➕ Prefix Sum

Kỹ thuật mảng cộng dồn giúp tính tổng một đoạn của mảng nhanh hơn.

1. Prefix Sum là gì?

Prefix Sum là mảng lưu tổng các phần tử từ đầu mảng đến vị trí hiện tại.

prefix[i] = prefix[i - 1] + a[i]

Ta thường tạo mảng prefix có thêm một phần tử 0 ở đầu.

prefix[0] = 0

2. Ví dụ

Mảng:

a = [2, 4, 6, 8, 10]

Prefix Sum:

prefix = [0, 2, 6, 12, 20, 30]

Ví dụ cần tính tổng đoạn từ vị trí 2 đến 4 (theo cách đánh số 1-based):

prefix[4] - prefix[1]
= 20 - 2 = 18

3. 💻 Code Python

a = [2, 4, 6, 8, 10]

n = len(a)

prefix = [0] * (n + 1)

for i in range(1, n + 1):

    prefix[i] = prefix[i - 1] + a[i - 1]

print(prefix)

Kết quả:

[0, 2, 6, 12, 20, 30]

4. 🔎 Tính tổng đoạn [l, r]

Với đoạn từ l đến r, ta dùng:

Sum(l, r) = prefix[r] - prefix[l - 1]

Đây là công thức rất quan trọng.

5. 🧪 Test case

Input:

5
2 4 6 8 10
2 4

Tính tổng các phần tử từ vị trí 2 đến 4.

Output:

18

6. 📝 Bài tập

Cho mảng:

3, 5, 2, 7, 4

Tính tổng các phần tử từ vị trí 2 đến 4.
