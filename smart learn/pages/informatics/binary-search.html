🔎 Binary Search

Tìm kiếm nhị phân trên mảng đã sắp xếp.

1. Binary Search là gì?

Binary Search là thuật toán tìm kiếm bằng cách liên tục chia đôi phạm vi cần tìm.

Điều kiện quan trọng: mảng phải được sắp xếp.

2. 🧠 mid là gì?

mid là vị trí nằm giữa left và right.

mid = (left + right) // 2

Ta lấy phần tử ở vị trí mid để quyết định tìm sang trái hay phải.

3. Cách hoạt động

1, 3, 5, 7, 9, 12, 15

Tìm số 12.

left = 0
right = 6
mid = 3

a[mid] = 7.

Vì: 7 < 12 → bỏ nửa bên trái.

left = mid + 1

Tiếp tục chia đôi cho đến khi tìm thấy 12.

4. 💻 Code Python

a = [1, 3, 5, 7, 9, 12, 15]

x = 12

left = 0
right = len(a) - 1

while left <= right:

    mid = (left + right) // 2

    if a[mid] == x:
        print("Tìm thấy")
        break

    elif a[mid] < x:
        left = mid + 1

    else:
        right = mid - 1
