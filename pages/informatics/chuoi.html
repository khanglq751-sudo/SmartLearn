🔤 Chuỗi trong Python

Học cách lưu trữ và xử lý dữ liệu dạng chuỗi.

1. Chuỗi là gì?

Chuỗi là một dãy các ký tự được đặt trong dấu nháy đơn hoặc dấu nháy kép. 

name = "SmartLearn"

2. Truy cập từng ký tự

Chỉ số của chuỗi bắt đầu từ 0. 

s = "Python"

print(s[0])
print(s[1])

Kết quả:

P
y

3. Một số cách xử lý chuỗi

s = "hello"

print(len(s))
print(s.upper())
print(s.lower())

len() → độ dài chuỗi.

upper() → chuyển thành chữ hoa.

lower() → chuyển thành chữ thường.

4. Đếm ký tự

s = "banana"

count = 0

for x in s:

    if x == "a":
        count += 1

print(count)

Kết quả:

3
